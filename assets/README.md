# SiteForge — лёгкий конструктор сайта

1. Загрузите все файлы в корень сайта через файловый менеджер.
2. Создайте пустую базу данных MySQL и пользователя к ней в панели хостинга.
3. Откройте `https://ваш-домен/install.php`, заполните форму — `config.php` будет создан автоматически.
4. Войдите через `/login`, затем откройте `/admin`.

Если хостинг показывает HTTP 500, загрузите `diagnostics.php` вместе с системой, откройте `/diagnostics.php` и удалите этот файл после проверки.

Если таблицы и соединение уже OK, но ошибка остаётся только в админке, войдите в систему и временно откройте `/admin-debug.php`. Он выведет техническое сообщение вместо HTTP 500. После проверки удалите файл.

Требования: PHP 8.0+, MySQL 5.7+ / MariaDB 10.3+, расширения PDO и pdo_mysql, право PHP на создание `config.php` в корневой папке.

Что включено: страницы, посты, категории, блог, товары/заказы, роли, комментарии с модерацией, SEO, slug, макеты, меню с вложенностью, кнопки header/footer, локализация, темы и каталог плагинов. Для заявок услуг вставьте в HTML страницы форму POST на `/order`, поля `csrf`, `kind=service`, `name`, `email`, `phone`, `message`.
