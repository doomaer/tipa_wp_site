Сюда (packages/themes/) можно положить тему для установки через админку:
раздел «Расширения» -> вкладка «Темы» -> «Установить».

Формат пакета:
  1) ZIP-архив, внутри которого ОДНА папка темы (например my-theme/style.css), либо
  2) уже распакованная папка my-theme/.

Обязательные файлы темы:
  style.css с заголовком в первой строке комментария:
     /*
     sf_theme: имя-темы
     Theme Name: Название для отображения
     Description: Краткое описание
     Version: 1.0
     */
  (необязательно) index.php, header.php, footer.php — шаблоны темы.

После установки активировать тему можно здесь же или в разделе «Настройки».
